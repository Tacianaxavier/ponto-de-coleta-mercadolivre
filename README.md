# Ponto de Coleta Mercado Livre 📦

Portal de Inscrição e Informações para Agência e Pontos de Coleta Mercado Livre / Mercado Envios.

## 🚀 Funcionalidades

- **Design Fiel ao Oficial**: Layout moderno e responsivo seguindo a identidade visual do Mercado Livre.
- **Formulário de Cadastro Multi-Etapas**:
  - Dados Pessoais / Responsável (Nome, CPF, E-mail, Telefone/WhatsApp)
  - Dados do Estabelecimento / Empresa (Razão Social, Nome Fantasia, CNPJ, Tipo de Negócio)
  - Endereço do Ponto (CEP com busca automática via ViaCEP, Logradouro, Número, Bairro, Cidade, Estado)
  - Espaço e Operação (Metragem disponível, Horário de funcionamento, etc.)
- **Validações e Máscaras**: Formatação automática de CPF, CNPJ, Telefone e CEP.
- **Integração WhatsApp**: Redirecionamento com mensagem estruturada com os dados do pré-cadastro direto para o WhatsApp de atendimento (+55 11 97234-7829).
- **Pronto para Vercel**: Deploy estático ultrarrápido sem dependências de build complexas.

## 🛠️ Tecnologias

- HTML5 Semântico
- CSS3 Responsivo (Mobile & Desktop)
- JavaScript Vanilla (sem frameworks pesados)
- API ViaCEP (consulta de endereços em tempo real)
