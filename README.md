# Informações sobre Pontos de Coleta 📦

Página independente de informações sobre pontos de coleta associados ao Mercado Livre. Não é canal oficial, não representa nem tem vínculo com o Mercado Livre.

## 🚀 Funcionalidades

- **Layout responsivo**: Compatível com dispositivos móveis e desktop.
- **Formulário de interesse Multi-Etapas**:
  - Dados básicos do responsável (Nome e Telefone/WhatsApp)
  - Dados do estabelecimento (Nome e Tipo de Negócio)
  - Endereço do Ponto (CEP com busca automática via ViaCEP, Logradouro, Número, Bairro, Cidade, Estado)
  - Espaço e Operação (Metragem disponível, Horário de funcionamento, etc.)
- **Validações e Máscaras**: Formatação automática de Telefone e CEP.
- **Integração WhatsApp**: Prepara uma mensagem para o contato particular da página; o usuário revisa e confirma o envio. Os dados não são enviados ao Mercado Livre.
- **Privacidade**: Não solicita CPF, CNPJ, e-mail ou data de nascimento. Não informe documentos ou senhas.
- **Pronto para Vercel**: Deploy estático ultrarrápido sem dependências de build complexas.

## 🛠️ Tecnologias

- HTML5 Semântico
- CSS3 Responsivo (Mobile & Desktop)
- JavaScript Vanilla (sem frameworks pesados)
- API ViaCEP (consulta de endereços em tempo real)
