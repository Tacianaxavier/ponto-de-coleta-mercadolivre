Requisitos para participar

Os itens abaixo são apenas pontos gerais para considerar; confirme os requisitos vigentes nos canais oficiais:

Estabelecimento físico regularizado

Espaço para armazenar pacotes com segurança

Horários e disponibilidade compatíveis com a operação

Acesso à internet estável para usar o sistema

Localização de fácil acesso para os clientes

Responsável treinado para receber e entregar pacotes

Confirme eventuais requisitos financeiros diretamente com a empresa

Capacidade de armazenamento a confirmar pelos canais oficiais
